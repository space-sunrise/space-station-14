# Инструментарий оптимизации текстур

Этот набор инструментов позволяет обнаружить и исключить неиспользуемые текстуры из сборки клиента, что уменьшает размер скачиваемого билда и экономит видеопамять игроков.

## Как это работает

### 1. Анализ использования текстур

Скрипт `find_unused_textures.py` сканирует:
- **YAML прототипы** (`Resources/Prototypes/`, `Resources/Maps/`) на наличие ссылок типа `sprite:`, `texture:`, `path:`
- **C# код** (`Content.Client/`, `Content.Server/`, `Content.Shared/`) на hardcoded пути к текстурам
- **Все текстурные файлы** в `Resources/Textures/` (RSI директории и отдельные PNG/SVG файлы)

Текстуры, не упомянутые в коде или прототипах, считаются неиспользуемыми.

### 2. Фильтрация при упаковке

Класс `UnusedTextureFilter` в `Content.Packaging` загружает список неиспользуемых текстур и интегрируется в процесс упаковки клиента через `AssetPassFilterDrop`, исключая неиспользуемые файлы из финальной сборки.

## Использование

### Шаг 1: Генерация списка неиспользуемых текстур

```bash
# Запустить анализ (результат сохранится в Resources/.unused_textures.json)
python3 Tools/find_unused_textures.py

# Или указать другой путь
python3 Tools/find_unused_textures.py --output custom_path.json

# Подробный вывод с примерами найденных ссылок
python3 Tools/find_unused_textures.py --verbose
```

### Шаг 2: Упаковка клиента с фильтрацией

При наличии файла `Resources/.unused_textures.json`, процесс упаковки автоматически исключит неиспользуемые текстуры:

```bash
# Обычная упаковка клиента (как в CI/CD)
dotnet run --project Content.Packaging client
```

Если файл `Resources/.unused_textures.json` отсутствует, упаковка пройдет без фильтрации с предупреждением в логах.

По данным последнего анализа:

## Интеграция в CI/CD

Для автоматической фильтрации в GitHub Actions workflows (`publish.yml`, `test-packaging.yml`):

```yaml
- name: Generate unused textures list
  run: python3 Tools/find_unused_textures.py

- name: Package client
  run: dotnet run --project Content.Packaging client --no-wipe-release
```

## Важные замечания

### Ложные срабатывания

Некоторые текстуры могут быть помечены как неиспользуемые, хотя на самом деле используются:
- Текстуры, загружаемые динамически (например, через конфигурацию)
- Текстуры, используемые внешними модами или плагинами
- Текстуры с нестандартными паттернами загрузки

### Принудительное включение текстур

Если текстура ошибочно помечена как неиспользуемая, есть два варианта:
1. **Добавить ссылку в прототип** (рекомендуется) - создать комментарий с путем к текстуре
2. **Модифицировать скрипт** - добавить путь в белый список в `find_unused_textures.py`

### Обновление списка

Список неиспользуемых текстур нужно обновлять:
- После добавления новых текстур
- После удаления прототипов или кода
- Периодически (например, раз в месяц)

## Техническая информация

### Формат RSI (Robust Station Image)

RSI - это формат спрайтов SS14:
- Директория с расширением `.rsi`
- Файл `meta.json` с метаданными
- Набор PNG файлов для различных состояний и направлений

Все файлы внутри RSI директории рассматриваются как группа - если RSI неиспользуема, все её файлы исключаются.

### Формат JSON отчета

```json
{
  "summary": {
    "total_texture_groups": 5596,
    "used_texture_groups": 4546,
    "unused_texture_groups": 1050,
    "total_size_bytes": 108865707,

  "unused_textures": [

      "path": "относительный/путь/к/текстуре.rsi",
      "size_bytes": 12345,
      "file_count": 5,
      "files": ["список", "файлов", "в", "группе"]
    }
  ]
}
```

## Устранение проблем

### Скрипт не находит некоторые ссылки

- Проверьте паттерны регулярных выражений в функциях `find_yaml_sprite_references()` и `find_csharp_texture_references()`
- Добавьте дополнительные паттерны для специфических случаев

### Упаковка не исключает текстуры

- Убедитесь, что файл `Resources/.unused_textures.json` существует
- Проверьте логи упаковки на наличие сообщений от `UnusedTextureFilter`
- Убедитесь, что `UnusedTextureFilter.IsTextureUnused()` корректно сопоставляет пути

### Игра не запускается после упаковки

- Возможно, критичная текстура была ошибочно исключена
- Проверьте логи клиента на наличие ошибок загрузки текстур
- Временно отключите фильтрацию (удалите `.unused_textures.json`)
- Добавьте проблемную текстуру в белый список

## Вклад в разработку

При добавлении новых текстур:
- Убедитесь, что они используются в прототипах или коде
- Если текстура для будущего использования, добавьте комментарий-ссылку в прототип

При удалении кода или прототипов:
- Удалите неиспользуемые текстуры или
- Обновите список неиспользуемых текстур
