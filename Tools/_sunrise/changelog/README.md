# Чейнджлог Sunrise

Добавляйте блок в описание PR. HTML-комментарии можно оставить: обработчик их удаляет.

```text
<!-- Автор необязателен: без него используется имя автора PR. -->
:cl: Автор

<!-- Типы: add, fix, tweak, remove. -->
- add: Первая строка новой возможности
  Вторая строка той же записи после Enter

<!-- Медиа относится к ближайшей предыдущей записи. -->
media: [Сначала видео](https://example.org/demo.webm)
media: ![Затем изображение](https://example.org/image.png)

<!-- Пустая строка или новый тип завершают предыдущую запись. -->
- fix: Следующая запись

:end-cl:
```

`:end-cl:` явно завершает блок. Две пустые строки подряд делают то же самое. Если границы нет, для совместимости блок читается до конца описания PR.

В Discord сохраняются переносы и порядок строк `media:` независимо от типа файла. Медиа разных записей разделяется чертой. Поддерживаются прямые HTTPS-ссылки, Markdown-ссылки и страницы сервисов вроде YouTube: для них Discord сам создаёт внешний предпросмотр. Максимум — 20 элементов на запись и 10 элементов в одном сообщении.

Для ручного запуска GitHub Actions используйте тот же формат, заменив заголовок на `:ci: Автор`.
