# Чейнджлог Sunrise

В PR запись начинается с `:cl: Автор`. Медиа указывается сразу после той строки, к которой относится:

```text
:cl: Автор
- add: Первая строка изменения
  Вторая строка той же записи
media: [Сначала видео](https://example.org/demo.webm)
media: ![Затем изображение](https://example.org/image.png)

- fix: Следующая запись
```

Порядок строк `media:` сохраняется в Discord. Пустая строка, новая запись или категория завершают многострочный пункт.
