# ENV для автоматических проверок

Для обычной проверки проекта переменные репозитория создавать не нужно: значения задают сценарии GitHub. CI — это автоматическая сборка и запуск тестов.

## Тесты и измерение времени

| ENV | Откуда берётся и что означает |
| --- | --- |
| `SHARD` | Номер группы тестов, которую запускает текущий исполнитель. Выбирается сценарием. |
| `PROFILE_RUNS` | Число повторных измерений. Поле `profile_runs` в **Profile Integration Test Timings**: `10`, `20`, `30` или `50`; по умолчанию `20`. |
| `MAX_PARALLEL_RUNNERS` | Число одновременно работающих исполнителей. Поле `max_parallel_runners`, от `1` до `20`; по умолчанию `5`. |
| `PROFILE_RUN` | Номер текущего повторения; сценарий заполняет его сам. |
| `DOTNET_gcServer` | Сценарий передаёт `1` для серверного режима управления памятью .NET при тестировании. |
| `BUILD_RESULT`, `CONTENT_TESTS_RESULT`, `INTEGRATION_TESTS_RESULT` | Результаты сборки и двух наборов тестов. Итоговая проверка требует `success` — успешного завершения каждого. |
| `SEQUENCE_URL`, `DUMP_URL` | Необязательные ссылки на сохранённые материалы для разбора зависшего теста. Заполняются после их загрузки в GitHub. |
| `GITHUB_WORKSPACE` | Рабочая папка репозитория. Нужна в том числе для проверки каталога перед очисткой результатов сборки. |
| `GITHUB_SHA`, `GITHUB_RUN_ID` | Хеш проверяемого коммита и номер запуска. Записываются в результаты измерений. |
| `GITHUB_OUTPUT`, `GITHUB_STEP_SUMMARY` | Служебные файлы GitHub для передачи параметров и формирования отчёта. |

`ROOT_DIR`, `SHARDING_SCRIPT`, `RESULTS_DIR` и `PROFILE_SHARD_COUNT` — внутренние значения скрипта, а не пользовательские ENV. Передача таких переменных извне не меняет их настройки.

## Автоматический перевод запроса в черновик

Связанный сценарий **PR: Auto Draft on Review Threads** имеет отдельную настройку. [Где вводить секреты](../how-to-env.md).

| Имя | Где задаётся | Назначение |
| --- | --- | --- |
| `AUTO_DRAFT_TOKEN` | Секрет GitHub, если стандартного ключа недостаточно | Ключ GitHub с доступом к репозиторию, запросам на слияние и их обсуждениям. Нужен для перевода запроса в черновик и обратно. |
| `GITHUB_TOKEN` | Автоматически | Стандартный ключ GitHub; используется, когда отдельный ключ не задан. Его прав может не хватать для смены состояния черновика. |
| `AUTO_DRAFT_TOKEN_CONFIGURED` | Автоматически | Признак наличия отдельного ключа. |
| `AUTO_DRAFT_LABEL`, `AUTO_DRAFT_COMMENT_MARKER` | Внутри сценария | Метка и служебный признак, по которым бот узнаёт собственные действия. |
| `AI_REVIEWERS`, `AI_REVIEWER_APPS` | Внутри сценария | Списки ботов и приложений, замечания которых учитываются. |
